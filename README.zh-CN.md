# 1in8b life｜80亿分之1人生模拟器

**从随机出生开始，体验环境、选择与机遇如何共同影响一生。**

[开始游玩](https://1in8b.run/zh-hans/) · [English](README.md) · [提交反馈](https://github.com/git-sanbu/1in8b-run/issues)

这是一款基于172个国家与地区公开统计的免费浏览器人生模拟游戏。你将从0岁开始，经历成长、求学、工作、家庭与健康事件，在重要时刻作出选择。

![人物、生活重心、人生记录与家庭界面示例](https://1in8b.run/images/1in8b-life-gameplay-1200.webp)

## 推荐体验的内容

- 按年度出生人数或人口比例抽取出生地，观察不同起点。
- 选择过去、现在或使用推估资料的未来世界。
- 调整每年的生活重心，在事件中作出抉择。
- 使用暂停、加速或自动抉择，按自己的节奏体验。
- 阅读国家统计与人生记录，比较环境和选择的影响。

## 如何开始

1. 打开[简体中文游戏页](https://1in8b.run/zh-hans/)。
2. 保留默认设置，或展开“人生设定”。
3. 点击“出生”，查看出生登记并开始人生。
4. 查看人生记录；需要备份时，通过“移转纪录”下载存档。

## 当前托管版本的功能边界

人生与设置保存在当前浏览器，可以导出和导入备份。社区故事与追思馆供浏览，互动仅保存在本机；当前版本没有接入原服务的付费通行证、云端账号与实时社区。

适合15岁以上，涉及死亡、疾病、战争与暴力等主题，不描绘具体场面。可使用“略过可怕的情节”或教学模式。

## 数据与理解方式

模拟参考[联合国人口展望](https://population.un.org/wpp/)、[世界银行公开数据](https://data.worldbank.org/)及网站列出的其他健康、教育和历史资料。统计资料年份不同，部分缺失值采用区域估算，未来情景使用推估。模拟结果不预测个人命运。

可查看[国家与地区统计](https://1in8b.run/zh-hans/c/)及页面来源说明。
